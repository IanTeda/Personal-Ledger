2Window Sizes · Settings › Display

Settings › Display at each Window Size (ADR-0042), Medium first because the Chrome is designed Medium-first. Medium is 720–1199px wide, Large 1200–1599px, X-Large 1600px and up; height never picks a Window Size. Settings at Medium is a drill-down: an index page, then each page with a breadcrumb heading that carries a page picker. Picked in #692 over a drawer, a plain drill-down, a header picker alone and a narrow docked index (prototype branch prototype/692-window-sizes). Settings goes up to the index, the caret after the page name opens the picker, [ and ] step sideways.

DESKTOP-119Medium · 960 × 1040. The index page. g s lands on the Settings index, one row per page with a one-line description. Its heading is plain Settings: no caret, because the index is already the full list. enter or a click opens a page.
