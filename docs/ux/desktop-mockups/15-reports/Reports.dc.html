Parents roll up like 18a; uncategorised spending is listed, never hidden.

DUI-061Explain a variance — from explain on a mismatched check. It narrows the search to transactions since the last check that passed, then lists likely causes: exact-amount pending first, then near the cut-off, then possible duplicates. Nothing is changed automatically. The adjustment is a real, categorised transaction, so reports still show it.
