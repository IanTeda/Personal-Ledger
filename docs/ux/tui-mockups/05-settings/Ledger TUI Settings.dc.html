settingsSettings — the Desktop's paged index, driven from the keyboard

Same sixteen pages, same order and same content as Desktop Settings (package 16), re-hosted in the TUI's one-view shell. The left pane is the index: moving through it with j/k swaps the page on the right immediately, so you can scan every page without opening it. l or enter moves focus into the page, and h or esc moves it back. Form pages edit a field in place and save when you press enter. List pages use the same n / e / d keys and forms as their full views. Each row in the index shows a scope glyph: ● syncs with the ledger, ○ stays on this device. Each page heading repeats its scope in words. Every page also opens by name: :settings <page>.
