# Mockup card IDs

Every card in the Desktop and TUI mockups has a product-prefixed ID, so a prompt like "DUI-001" or "TUI-001" is unambiguous. IDs are numbered in folder order, then card order, and are stable: new cards take the next number, they do not renumber. The old per-file ID (`1a`, `16k`) is kept as `data-local-id` on the card and in the README prose.
