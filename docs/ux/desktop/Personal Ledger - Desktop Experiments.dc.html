Personal Ledger, desktop experiments. Ideas being tried out, not part of the main design. Main design: Ledger Desktop Shell.
4+5Documents + Events, combined: three ways to make them one place in the nav
Both are dated, both link to transactions, and a document is often the proof of an event: a statement for a balance check, a claim for an incident, the bookings for a trip. Each option replaces the two rail items with one; Notifications stays as is.
5fRecords: one table. Documents and Events in one list, newest first. Events are grey rows; their files nest under them (space expands). Files with no event sit at the top level, so Documents works as before. The second rail combines both sets of filters. Least new to learn; the list is long. g f stays; g e is freed.
